# Sequoia Social

A Cinny-based Matrix client focused on Neurodivergent individuals, featuring a soft, elegant, and uncomplicated interface, End to End Encryption, bridges to all your favourite platforms, and a connection to Sequoia Profiles.

- [Roadmap](./ROADMAP.md)
- [Contributing](./CONTRIBUTING.md)

## Getting started
The web app is available at [app.social.sequoiasupport.com](https://app.social.sequoiasupport.com/) and gets updated with all changes. Things may break or be broken, so if you find a bug, please open an issue!

Desktop app is planned.

## Self-hosting
Self Hosting is not currently supported, however if you are willing to sacrifice a few features, [cinny](https://github.com/cinnyapp/cinny) has versions you can Self Host that will be similar to this. Or you can just try to use this repo I guess (If you do, adequate credit IS REQUIRED).
